✅ Solução 1: Proteção do App (Anamnese)

✓ COMPLETO

Problema

App travava quando cliente retornava após 1 ano sem validar anamnese expirada.

Solução Implementada

  • Função precisaRenovarAnamnese() verifica se > 365 dias
  • Gate obriga atualização ANTES de ServiceSelector (step 2)
  • Campo data_anamnese salvo como ISO date (YYYY-MM-DD)
  • Validação robusta com try-catch

Código (src/App.js)

function precisaRenovarAnamnese(anamneseObj) { if(!anamneseObj || typeof anamneseObj !== 'object') return false; if(!anamneseObj.data_anamnese) return false; try { const dataUltima = new Date(anamneseObj.data_anamnese); if(isNaN(dataUltima.getTime())) return false; const agora = new Date(); const diasPassados = (agora - dataUltima) / (1000 * 60 * 60 * 24); return diasPassados >= 365; } catch(e) { return false; } }
