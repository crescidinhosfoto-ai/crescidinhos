🏗️ 3. Arquitetura do Sistema

Fluxo de Autenticação

Usuario digita email ↓ React: enviarCodigo(email) ↓ fetch(WEBHOOK_ENVIAR_CODIGO) → POST /webhook/enviar-codigo-email ↓ n8n Webhook recebe: {email, codigo} ↓ JavaScript Node: Transforma dados ↓ Gmail Node: Envia email HTML com código ↓ Response Webhook: Retorna {success: true} ↓ React: sessionStorage salva código temp ↓ Usuario digita código e confirma

Proteção: Anamnese Expirada

Usuario tenta marcar horário ↓ React verifica: precisaRenovarAnamnese() ↓ Se data_anamnese > 365 dias atrás ↓ Bloqueia ServiceSelector (step 2) ↓ Força AnamneseUpdateCard ↓ Usuario atualiza dados ↓ data_anamnese salvo como ISO date ↓ Permite continuação

⚛️ 5. Código React (App.js)

Função: precisaRenovarAnamnese()

Verifica se anamnese expirou (> 365 dias):

function precisaRenovarAnamnese(anamneseObj) { if(!anamneseObj || typeof anamneseObj !== 'object') return false; if(!anamneseObj.data_anamnese) return false; try { const dataUltima = new Date(anamneseObj.data_anamnese); if(isNaN(dataUltima.getTime())) return false; const agora = new Date(); const diasPassados = (agora - dataUltima) / (1000 * 60 * 60 * 24); return diasPassados >= 365; } catch(e) { return false; } }

Função: enviarCodigo()

Envia código via webhook n8n:

const enviarCodigo=async(emailParam)=>{ const em=(emailParam||email||'').trim().toLowerCase(); if(!em)return; setLoading(true);setErroAuth(''); try{ // Chama webhook n8n + Gmail diretamente const codigoAleatorio = Math.random().toString().substring(2,8); const resWH = await fetch(WEBHOOK_ENVIAR_CODIGO, { method:'POST', headers:{'Content-Type':'application/json'}, body:JSON.stringify({email:em, codigo:codigoAleatorio}) }); console.log('Webhook enviou código para '+em, 'Status:', resWH.status); if(!resWH.ok) { const errText = await resWH.text(); console.error('Erro webhook:', resWH.status, errText); throw new Error('Erro ao enviar código'); } sessionStorage.setItem('_codigo_temp_'+em, codigoAleatorio); setEmail(em); setAuthTela('codigo'); }catch(e){setErroAuth('Não conseguimos enviar o código. 📝 6. Procedimentos e Testes

Teste: Envio de Código

  1. Abre https://app.crescidinhosfoto.com.br em incógnito
  2. Aperta Ctrl+Shift+R (força limpeza de cache)
  3. Clica "Receber código por e-mail"
  4. Digita email de teste
  5. Aguarda 10 segundos
  6. Verifica se email chegou (verificar Spam também)

Monitorar n8n Executions

  1. Abre n8n: https://ribbitingboar-n8n.cloudfy.live
  2. Vai em "Crescidinhos — 📧 Enviar Código Email"
  3. Clica aba "Executions"
  4. Procura por execuções recentes
  5. Se houver erros, clica para detalhar

Debug via Console

1. Abre DevTools: F12 2. Vai para Console 3. Procura por: - "Webhook enviou código para..." - Erros em vermelho (Error at fetch) 4. Se houver erro, anota o HTTP status

🔧 7. Troubleshooting

Email não chega

Sintoma: "Não conseguimos enviar o código"

Checklist:
  • Verificar n8n Executions: há execução recente?
  • Se SIM: Gmail node retornou erro? (verificar detalhes)
  • Se NÃO: Webhook não foi chamado (problema no App.js ou deploy)
  • Verificar Gmail: "Ativar apps menos seguros" em segurança da conta
  • Verificar spam/lixo do email

Deploy não saiu

Sintoma: Código novo não aparece em produção

Solução:
  • Aguardar 10-20 minutos (GitHub Actions)
  • Ctrl+Shift+R para hard refresh
  • Abrir incógnito (sem cache do navegador)
  • Verificar GitHub Actions: há workflow em progresso?

App trava ao marcar

Sintoma: App congela no step 1

Causa Provável: Anamnese não está sendo validada
Solução:
  • Verificar se precisaRenovarAnamnese() foi deployado
  • Verificar console (F12) por erros
  • Atualizar anamnese do cliente no Supabase

Webhook retorna 404

Sintoma: fetch retorna 404 Not Found

Causa: Webhook não está ativo no n8n
Solução:
  • Abrir workflow no n8n
  • Verificar se status é "Published" (verde)
  • Se não: clicar "Activate"
  • Verificar path: deve ser "enviar-codigo-email"
  • Verificar método: deve ser "POST"
